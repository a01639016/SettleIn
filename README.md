# SettleIn landing page

Brand-aligned, responsive landing page for SettleIn. All visible copy is in English and every main CTA links to the live prototype.

## Publish on GitHub Pages

Replace the existing root `index.html` with this folder's `index.html`, then add `styles.css`, `script.js`, and the `assets` folder to the same repository root. Commit and push the changes; GitHub Pages will update the existing URL automatically.

If the repository already contains files with these names, preserve the `prototype` folder and replace only the matching landing-page files.
